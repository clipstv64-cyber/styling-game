# Style Studio — Atelier Edition V2

Grafisch überarbeitetes Styling-Spiel mit neuen ImageGen-Hintergründen, Werkzeugen und Figurenmaterialien.

## Fertiges Spiel herunterladen

[**Neue Version mit überarbeiteter Figur herunterladen**](https://github.com/clipstv64-cyber/styling-game/raw/refs/heads/grafik-atelier/downloads/Style-Studio-Atelier-v2-kompakt.zip)

ZIP vollständig entpacken. Die Spiel-Dateien und alle neuen Grafiken sind enthalten.

## Neue Figur und kleinere Dateien

Die V2 ersetzt Augen, Nase, Lippen und Augenbrauen durch separat gerenderte ImageGen-Komponenten. Der Haaransatz und die Körperproportionen sind neu abgestimmt. Styling, Augenfarben und Make-up bleiben bearbeitbar. Die Grafiken verwenden platzsparendes WebP bei unveränderten Bildmaßen.

[Vorschau der neuen Figur](https://github.com/clipstv64-cyber/styling-game/blob/grafik-atelier/previews/figur-v2.png)

## Starten

Im entpackten Spielordner:

```sh
python3 -m http.server 8000
```

Danach `http://localhost:8000` im Browser öffnen. Keine npm-Installation und kein API-Schlüssel erforderlich.
