# Style Studio — Atelier Edition V3

Grafisch überarbeitetes Styling-Spiel mit neuen ImageGen-Hintergründen, Werkzeugen und Figurenmaterialien.

## Fertiges Spiel herunterladen

[**Neue Version mit überarbeiteter Figur herunterladen**](https://github.com/clipstv64-cyber/styling-game/raw/refs/heads/grafik-atelier/downloads/Style-Studio-Atelier-v3-kompakt.zip)

ZIP vollständig entpacken. Die Spiel-Dateien und alle neuen Grafiken sind enthalten.

## Neue Figur und kleinere Dateien

Die V3 verkleinert die Augen um rund 12 Prozent und stimmt die Mascara-Koordinaten darauf ab. Die Haare fallen breiter und leicht geschwungen über die Schultern. Schultern, Hals und Körperlänge sind angepasst; alle Kleidungsstücke folgen denselben Proportionen. Das Gesicht besteht weiterhin aus separat gerenderten ImageGen-Komponenten. Styling, Augenfarben und Make-up bleiben bearbeitbar. Die Grafiken verwenden platzsparendes WebP bei unveränderten Bildmaßen.

[Vorschau der neuen Figur](https://github.com/clipstv64-cyber/styling-game/blob/grafik-atelier/previews/figur-v3.png)

## Starten

Im entpackten Spielordner:

```sh
python3 -m http.server 8000
```

Danach `http://localhost:8000` im Browser öffnen. Keine npm-Installation und kein API-Schlüssel erforderlich.
